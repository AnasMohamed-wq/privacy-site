# privacy-site – صفحة سياسة الخصوصية الثابتة

صفحة ثابتة ثنائية اللغة (عربي/إنجليزي) مبنية على:
- `docs/privacy/PRIVACY_DATA_AUDIT.md` (مصدر كل بند)
- `docs/privacy/PRIVACY_POLICY_OUTLINE.md` (ترتيب الأقسام)
- `docs/privacy/OPEN_QUESTIONS.md` (الـ placeholders)

الكيان: **الكيان الرقمي (Digital Entity)** — الإصدار **v1.1** (6 أكتوبر 2026).

الملفات مستقلة تمامًا عن مستودع المشروع (لا ربط، لا مكتبات خارجية، لا تتبع).

## الملفات

| الملف | الوصف |
|-------|-------|
| `index.html` | الصفحة كاملة (CSS + JS داخلية، بدون أي طلب خارجي) |
| `.nojekyll` | يمنع GitHub من معالجة المجلد بـ Jekyll |
| `README.md` | هذا الملف |

## خطوات الرفع اليدوي على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (مثال: `privacy-site`) أو استخدم جذر مستودع موجود.
2. ارفع الملفات الثلاثة إلى جذر المستودع (أو إلى مجلد `/docs` إن أردت استخدام docs Pages).
3. من إعدادات المستودع: **Settings → Pages → Source: Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` (أو `/docs` إن رفعت فيها) ثم **Save**.
5. انتظر دقيقة حتى يظهر رابط الموقع في أعلى صفحة Pages.

**الرابط المتوقع:**

```
https://<اسم-المستخدم>.github.io/<اسم-المستودع>/
```

مثال: إذا رفعت المستودع باسم `privacy-site`:

```
https://<اسم-المستخدم>.github.io/privacy-site/
```

رابط القسم المباشر (مطلوب لمتجري Google Play / App Store):

```
https://<اسم-المستخدم>.github.io/privacy-site/#delete-account
```

> **ملاحظة أمان:** قبل النشر على متجر، يُفضَّل تفعيل HTTPS (مفعّل افتراضيًا في GitHub Pages) وتثبيت النطاق الخاص إن وُجد.

## قبل النشر – قائمة الـ placeholders المتبقية

كل placeholder بالشكل `[[يلزم تحديد: ...]]` ومُعلَّم بصريًا (خلفية صفراء) داخل `index.html`.

| # | المكان في الصفحة | السؤال من OPEN_QUESTIONS | مطلوب |
|---|------------------|---------------------------|-------|
| 1 | §1 من نحن | س2 | العنوان البريدي للكيان |
| 2 | §1، §9، §13 | س3 | بريد الخصوصية وبريد طلبات الحذف |
| 3 | §5 الأذونات | س27 | الأذونات الفعلية من AndroidManifest.xml / Info.plist (فحص الـ Frontend) |
| 4 | §2 جهاز | س28 | مكان حفظ JWT في تطبيق Flutter |
| 5 | §13 التواصل | س37 | قناة الإبلاغ عن الثغرات الأمنية |

أي بند غير مذكور بالأسفل يظهر كـ `[[يلزم تحديد: ...]]` في كلا النسختين العربية والإنجليزية.

## ملاحظات محتوى

- لا إعلانات، لا analytics، لا نماذج، لا إعادة توجيه، لا مكتبات خارجية.
- طُبِّقت هوية «الكيان الرقمي» البصرية على الصفحة (ألوان العلامة، كروت، أيقونات SVG داخلية، دائرة زخرفية) دون أي طلب خارجي.
- الشعار: لم يتوفر ملف شعار، فالصندوق مخصص له في الترويسة (`.logo-box` يظهر تلقائيًا عند إضافة `logo.png` بجانب `index.html`).
- المحتوى الأساسي نص HTML حقيقي في النسختين؛ JS يُستخدم فقط لتبديل اللغة (تعطيله لا يمنع القراءة – النسخة العربية تظهر افتراضيًا).
- صفحات المدير الداخلية (`/web/`, `/admin/`) **غير مذكورة** عمدًا (أداة داخلية وفق التدقيق).
- حالة الحذف الحالية صريحة: لا يوجد endpoint حذف في الباك إند — النشر في المتاجر يتطلب إغلاق هذا (س41).
